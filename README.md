# Aster & Row

A responsive, editorial fashion storefront inspired by the restrained layout and typography of the Minimalin theme. The implementation and brand are original.

## Run locally

Open `index.html` directly, or start any static server in this folder.

## Features

- Responsive desktop and mobile navigation
- Search and category filtering
- Wishlist toggles
- Functional cart drawer and totals
- Newsletter feedback
- Original AI-generated hero art
